
# LoyfusAnime - Frontend 🎥

Bem-vindo ao repositório do **LoyfusAnime - Frontend**! Este projeto é a interface do usuário de uma plataforma voltada para amantes de animes, fornecendo uma experiência rica para explorar, buscar e visualizar informações sobre diferentes animes. 🚀

## 🛠️ Tecnologias Utilizadas

Este projeto utiliza as seguintes tecnologias e ferramentas:

- **React** - Biblioteca JavaScript para construção de interfaces.
- **Axios** - Cliente HTTP para consumir APIs.
- **React Router** - Gerenciamento de rotas no React.
- **CSS Modules** - Estilização modular e escopada.

## O que faz

Interface do [LoyfusAnime](https://github.com/loyfus/animeBackEnd): lista de
animes em alta com paginação, busca e página de detalhe com link de streaming.

## Como rodar

```bash
npm install
npm start
```

O front consome a API do backend. Ajuste a URL base em `src/api/api.js`
apontando para a sua instância.

## Limite de taxa

Os dados vêm da [AniList](https://anilist.co), que tem limite de taxa.
Respeite os [Termos de Uso](https://anilist.co/terms).
